# Catálogo iPhones — Área de Membros

Projeto pronto para publicação via GitHub Pages.

## Como publicar
1. Extraia o ZIP.
2. Envie todos os arquivos e pastas para a raiz do repositório.
3. No GitHub, abra **Settings > Pages** e publique a branch principal pela pasta raiz.
4. A página inicial é `index.html`.

## Permissões configuradas
- **Acesso gratuito (plano 0):** visualiza todos os catálogos; conteúdos, aulas e downloads ficam bloqueados.
- **Acesso 1:** conteúdos, aulas, downloads e edição do catálogo iPhone liberados; edição de Xiaomi, Realme e Apple bloqueada.
- **Acesso 2:** acesso completo.

## Observação importante de segurança
Arquivos e links incluídos em um site estático público podem ser encontrados por inspeção do código ou acesso direto ao endereço. Para proteger conteúdos pagos de forma real, armazene downloads e links em uma área privada com autorização no backend/Supabase, liberando-os somente após validar o plano do usuário.
